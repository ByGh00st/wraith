# Support

| Need | Where to go |
| :--- | :--- |
| Installation and first session | [Getting started](https://github.com/ByGh00st/wraith/wiki/Getting-Started) |
| Commands and updates | [Daily workflow](https://github.com/ByGh00st/wraith/wiki/Daily-Workflow) |
| TLS / JA3 / JA4 scope | [TLS and HTTP](https://github.com/ByGh00st/wraith/wiki/TLS-and-HTTP) |
| Failed setup or cleanup | [Troubleshooting](https://github.com/ByGh00st/wraith/wiki/Troubleshooting) |
| Reproducible bug or feature request | [Issue forms](https://github.com/ByGh00st/wraith/issues/new/choose) |
| Suspected security vulnerability | [Private reporting policy](SECURITY.md) |

For an issue, provide the exact command, version or commit, Linux distribution, kernel, selected interface, expected behavior and sanitized error output. State whether the problem is reproducible in a disposable environment. Remove credentials, private keys, tokens and identifying packet contents.

If cleanup fails, retain recovery state, resolve the reported resource failure and retry `sudo wraith -x`. See the recovery guide before changing host firewall or resolver settings manually.

Support is community-based; no response-time or availability guarantee is published. A site rejecting a Tor exit is not, by itself, evidence of an implementation vulnerability or a guarantee that another profile will work.
